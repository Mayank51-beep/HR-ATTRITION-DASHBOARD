# HR-ATTRITION-DASHBOARD

# 📊 HR Attrition Analytics Dashboard — Excel

An interactive **HR Attrition Analytics Dashboard** built in Microsoft Excel to analyze employee attrition patterns across departments, job roles, tenure, gender, and education fields.

The project demonstrates an end-to-end **data cleaning → transformation → analysis → visualization → business insights** workflow using Excel and Power Query.

---

## 🎯 Project Objectives

* Calculate and monitor **overall employee attrition rate**
* Identify departments and job roles with higher attrition
* Analyze attrition across **Years at Company**
* Explore attrition patterns by **Gender** and **Education Field**
* Build an interactive dashboard using **PivotTables, PivotCharts, and Slicers**
* Generate actionable HR insights to support **employee retention strategies**

---

## 🛠️ Tools & Techniques

* **Microsoft Excel**
* **Power Query** — data cleaning and transformation
* **PivotTables & PivotCharts** — analysis and visualization
* **Slicers** — interactive filtering
* **Calculated Columns & Formulas**
* **Attrition Flag** — converted `Yes/No` attrition into `1/0` for analysis
* **KPI Cards** — overall attrition monitoring

---

## 🔄 Project Workflow

**Raw HR Data**
↓
**Power Query Cleaning & Transformation**

↓
**Actionable Business Insights**

---

## 📈 Dashboard Features

### KPI

* **Overall Attrition %**

### Analysis

* Attrition % by **Department**
* Attrition % by **Job Role**
* Attrition % by **Years at Company**
* Interactive analysis using **Gender** and **Education Field** slicers

### Interactivity

Users can filter the dashboard using slicers to explore how attrition changes across different employee segments.

---

## 💡 Key Insights

The dashboard helps identify:

1. **Departments and job roles** where attrition is concentrated.
2. **Tenure groups** that may require stronger retention efforts.
3. Differences in attrition across **gender and education segments**.
4. Roles requiring deeper investigation into workload, career development, compensation, or employee experience.
5. Opportunities for HR to move from **general retention strategies toward targeted interventions**.

> **Note:** The dashboard identifies patterns and associations in the available data; it does not establish the underlying causes of employee attrition.
